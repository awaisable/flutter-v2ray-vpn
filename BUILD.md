# Build Instructions

## Prerequisites

- Flutter SDK 3.16+ installed
- Android Studio with Android SDK
- Xcode (for iOS builds)
- Physical Android device or emulator

Check your setup:
```bash
flutter doctor
```

---

## Quick Build (Android APK)

### 1. Clone the repo
```bash
git clone https://github.com/awaisable/flutter-v2ray-vpn.git
cd flutter-v2ray-vpn
```

### 2. Regenerate Android/iOS with v2 embedding
```bash
flutter create --org com.example --project-name flutter_v2ray_vpn .
```

**Important:** When prompted "Would you like to overwrite...", type `a` (all) and press Enter. This regenerates the Android/iOS folders with proper v2 embedding while keeping your `lib/` folder intact.

### 3. Restore custom Android config
```bash
cp ci_android/AndroidManifest.xml android/app/src/main/AndroidManifest.xml
cp ci_android/gradle.properties android/gradle.properties
```

### 4. Get dependencies
```bash
flutter pub get
```

### 5. Build debug APK
```bash
flutter build apk --debug
```

**Output:** `build/app/outputs/flutter-apk/app-debug.apk`

### 6. Install on device
```bash
# Via USB
adb install build/app/outputs/flutter-apk/app-debug.apk

# Or run directly
flutter run
```

---

## Build Release APK (for distribution)

```bash
flutter build apk --release --split-per-abi
```

**Output:**
- `build/app/outputs/flutter-apk/app-arm64-v8a-release.apk` (most phones)
- `build/app/outputs/flutter-apk/app-armeabi-v7a-release.apk` (older phones)
- `build/app/outputs/flutter-apk/app-x86_64-release.apk` (emulators)

## iOS Build (requires Mac)

### 1. Open Xcode project
```bash
open ios/Runner.xcworkspace
```

### 2. Configure signing
- Select the Runner target
- Go to "Signing & Capabilities"
- Select your Team
- Change Bundle Identifier to something unique (e.g., `com.yourname.vpn`)

### 3. Add Network Extension capability
- Click "+ Capability"
- Add "Network Extensions"
- Check "Packet Tunnel"

### 4. Add App Groups capability
- Click "+ Capability"
- Add "App Groups"
- Add group: `group.com.yourname.vpn`

### 5. Create Packet Tunnel Provider target
- File → New → Target
- Select "Network Extension"
- Product Name: `PacketTunnel`
- Language: Swift
- Replace `PacketTunnelProvider.swift` with the one in `ios/PacketTunnel/`

### 6. Build
```bash
flutter build ios --release
```

Or run directly on a connected iPhone:
```bash
flutter run
```

## Troubleshooting

### "Build failed due to use of deleted Android v1 embedding"
Run step 2 again (`flutter create .`) to regenerate the Android folder.

### "VPN permission denied"
On Android, the app will request VPN permission on first connect. Make sure to allow it.

### "No servers found"
Check your internet connection. The app fetches servers from GitHub on launch.

### Gradle build fails
```bash
cd android
./gradlew clean
cd ..
flutter clean
flutter pub get
```

## Project Structure

```
lib/
├── core/          # Utilities, error handling
├── data/          # HTTP client, parsers, repositories
├── domain/        # Business logic, entities, use cases
```

## Notes for M1 Mac

- Everything should work out of the box
- If you get Rosetta warnings, ignore them (Flutter handles this)
- For iOS builds, make sure Xcode Command Line Tools are installed:
  ```bash
  xcode-select --install
  ```
